# Baby Fadia Storytelling V4

This version removes all public references to three events. The public homepage tells an illustrated Month 1 to Month 7 journey. Guests enter a private code before seeing celebration details.

## Review
1. Open `index.html`.
2. Scroll through the illustrated journey.
3. Enter any invitation code to review the invitation page.
4. `invite.html` is currently a visual demo and must be connected to Supabase before real RSVP collection.

## Important production behavior
- Public homepage: story, invitation-code access and gallery preview only.
- Private invitation: only events assigned to that household.
- Private gallery: only albums assigned to that household.
